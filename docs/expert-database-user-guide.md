# 北京市哲学社会科学专家库 · 使用指南

版本：v1.0　日期：2026-07-16

本指南面向四类使用者：**个人申报人**（专家本人或代填人员）、**单位审核员**、**市级审核员**、**管理员**。各角色能看到的菜单和操作范围不同，见下表。

## 1. 角色与权限一览

| 角色 | 能做什么 | 看不到什么 |
|---|---|---|
| 个人申报人 | 填报/编辑自己的专家档案，维护自己的成果、决策影响记录、学术兼职，提交审核，撤回重填 | 其他专家的档案、审核操作入口 |
| 单位审核员 | 审核**本单位**提交的专家档案（通过/退回），查看审核历史 | 其他单位提交的档案（后端按 `所属单位` 强制过滤，不是前端隐藏） |
| 市级审核员 | 审核所有已通过单位审核、待市级审核的专家档案（通过/退回） | 还没走完单位审核的档案 |
| 管理员 | 以上全部权限 + 用户/角色/字典/菜单管理，可直接改写任意专家的审核状态 | 无限制 |

角色和"所属单位"由管理员在**用户管理**里给账号分配，不是自己能改的。

## 2. 登录

打开系统地址，输入账号、密码、图形验证码，点"登录"。首次使用请找管理员开通账号并确认自己的角色/所属单位是否已经设置正确——**如果登录后侧边栏是空的或者缺菜单，先找管理员确认角色分配和所属单位，不是账号本身有问题。**

> 有个交互上的小提醒：如果管理员刚给你调整过角色/权限，你需要**重新登出登录一次**才能让新权限生效，单纯刷新页面有时不够。

## 3. 个人申报人：填报专家档案

### 3.1 新增专家主档

菜单：**专家库 → 专家主档 → 新增**。表单分三部分，对应专家画像的前三个维度：

**背景信息**：姓名、性别、民族、政治面貌、所在单位、院系/部门、行政职务、专业技术职称、办公电话、手机号码、电子邮箱、通讯地址、最高学历、最高学位、毕业院校、所学专业、人才计划、荣誉称号。

**学科领域**：一级学科、二级学科、交叉学科领域、学科平台/研究基地。

**研究主题**：重点研究方向、研究关键词（多个关键词用逗号分隔——**这个字段会被检索功能拿来做主题匹配，务必填准确**）、所属政策领域、主要研究对象、当前关注议题、区域/国别研究专长、研究方法专长。

新增时默认是**草稿**状态，只有自己能看到、能改。

### 3.2 补充研究成果（第四维度）

菜单：**专家库 → 研究成果 → 新增**，需要填专家 ID（在专家主档列表里能看到自己档案的 ID）。

| 字段 | 说明 |
|---|---|
| 成果类型 | 著作 / 学术论文 / 研究报告 / 决策咨询成果 / 获奖成果 / 课题项目 |
| 成果级别 | 国家级 / 省部级 / 厅局级 / 一般级——**这个级别直接决定该条成果在综合排序里的得分权重**，如实填写 |
| 关键词 | 该成果的主题关键词，用于检索时的相关性匹配，和主档的"研究关键词"一样重要 |
| 检索相关次数 | 可选，留空即可，暂不影响排序 |

### 3.3 补充决策影响记录（第五维度）

菜单：**专家库 → 决策影响记录 → 新增**。这是"成果被采纳、被批示"的记录，也是本系统区别于普通专家名录的核心指标。

| 字段 | 说明 |
|---|---|
| 采纳类型 | 内参/专报采用、部门采纳、领导批示、进入政策文件、参与政策起草/咨询论证 |
| 采纳/批示单位级别 | 国家级 / 中央 / 省部级 / 厅局级 / 区县级——**级别越高，决策影响得分越高** |
| 采纳/批示单位名称、时间、佐证材料描述 | 如实填写，方便后续核实 |

### 3.4 补充学术兼职

菜单：**专家库 → 学术兼职 → 新增**：兼职类型（学术团体任职/专业委员会任职/政府决策咨询机构兼职等）、任职机构名称、担任职务、起止时间。学术兼职数量会计入"社会贡献得分"。

### 3.5 提交审核

档案和成果都填好之后，去**专家库 → 审核台 → 我发起的**，找到自己的档案，点"提交审核"。状态会从**草稿**变成**待单位审核**。

| 状态 | 含义 |
|---|---|
| 草稿 | 还没提交，可以随便改 |
| 待单位审核 | 已提交，等本单位审核员处理 |
| 单位已退回 | 单位审核员退回了，看审核意见后修改，重新提交 |
| 待市级审核 | 单位审核通过，等市级审核员处理 |
| 市级已退回 | 市级审核员退回了，看审核意见后修改，重新提交 |
| 已发布 | 市级审核通过，正式收录，**只有这个状态的专家才会出现在检索结果里** |

## 4. 单位审核员 / 市级审核员：审核操作

菜单：**专家库 → 审核台 → 待我审核的**。

- 单位审核员看到的是"待本单位审核"表格，只包含本单位提交的档案。
- 市级审核员看到的是"待市级审核"表格，不限单位。

每一行可以：
- **通过**：流转到下一环节（单位审核通过 → 待市级审核；市级审核通过 → 正式发布）
- **退回**：会弹窗要求填写审核意见，必填，退回后申报人能在自己的"我发起的"里看到这条意见
- **审核记录**：查看这份档案完整的流转历史（时间线形式）

## 5. 专家检索与推荐排序

菜单：**专家库 → 专家检索推荐**。这是给"要找某个领域权威专家"的场景用的，不是简单的名单搜索。

**怎么用**：输入检索主题（比如"防汛方案"），可选叠加一级学科/区域国别专长/职称筛选，点检索。只有**已发布**的专家会出现在结果里。

**结果里每一列的含义**：

| 列 | 含义 |
|---|---|
| 相关性 | 检索主题和该专家的成果/标签匹配程度，0%~100% |
| 成果分 | 该专家全部成果按"级别权重 × 篇数"算出来的分数 |
| 决策影响分 | 该专家全部决策影响记录按"采纳单位级别权重 × 次数"算出来的分数 |
| 社会贡献分 | 学术兼职数量 + 是否有荣誉称号 算出来的分数 |
| 综合得分 | 上面几项按权重加权求和，**这个决定了排序** |

计算公式：`综合得分 = w1×成果分×相关性 + w2×决策影响分×相关性 + w3×职称权重 + w4×社会贡献分`。权重 w1~w4 和各级别对应的分值都可以在字典管理里调（见第 6.2 节），不需要改代码。

## 6. 管理员操作指南

### 6.1 用户管理

菜单：**超级管理员 → 用户管理**。新增/编辑用户时：

- **所属单位**：选择该用户所属的单位（用于三级审核的数据归属）。个人申报人和单位审核员**必须**设置，否则申报人提交后没有单位归属、单位审核员看不到任何待审数据。
- **用户角色**：分配"专家库-个人申报人" / "专家库-单位审核员" / "专家库-市级审核员"，管理员账号沿用系统自带的超级管理员角色即可。

### 6.2 字典管理（调整评分权重）

菜单：**系统工具 → 字典管理**，找 `expert_` 开头的 5 个字典类型：

| 字典类型 | 调整什么 |
|---|---|
| `expert_achievement_level` | 成果级别对应的权重（国家级/省部级/厅局级/一般级） |
| `expert_adoption_level` | 采纳单位级别对应的权重 |
| `expert_title_level` | 职称对应的权重 |
| `expert_social_weight` | 学术兼职、荣誉称号的加分权重 |
| `expert_ranking_weight` | 综合排序四个分项（achievement/influence/title/social）各自的权重 w1~w4 |

改字典明细里的"扩展值"（对应权重数字），保存后**立即生效**，检索时会实时按新权重计算，不需要重启服务。

### 6.3 单位数据维护 —— 目前的已知限制

**这一项目前没有管理界面**：新增/编辑"单位"（比如要新增一个学校）现在只能由技术人员直接操作数据库，管理员在系统里没有对应的菜单页面可以自己维护。如果需要经常新增单位，建议尽快补一个"单位管理"页面（我可以帮你加，说一声就行）。

### 6.4 专家标签 —— 目前的已知限制

**标签库**（系统工具菜单里的"标签库"）目前只能维护标签本身（比如新增"水利工程"这个标签），但**没有界面能把标签关联到具体某个专家**——这个关联目前只有后端接口，没有前端入口。如果检索场景需要靠标签做更精细的匹配，这个也建议后续补上。

## 7. 常见问题

**Q：我提交审核之后想改怎么办？**
A：审核中的档案不能改。如果对方还没处理，先联系审核员退回给你；退回后状态变回可编辑，改完重新提交。

**Q：为什么检索不到某个专家？**
A：检查这位专家的档案状态是不是"已发布"——只有发布的专家会出现在检索结果里。其次检查关键词是否命中该专家的成果关键词或标签。

**Q：忘记密码怎么办？**
A：找管理员在用户管理里点"重置密码"，会重置为默认密码，登录后自己再改。

**Q：单位审核员能看到别的单位的专家吗？**
A：看不到，这是后端强制按"所属单位"过滤的，不是前端做的隐藏，绕不过去。

**Q：登录后菜单不全/看不到专家库？**
A：找管理员确认角色和所属单位有没有配置对；如果管理员刚改完权限，你需要重新登出登录一次。
