## 分支与范围

`master` 归档当前专家库功能，后续 Agent 功能从该基线的 `codex/expert-agent` 分支开发。

本次以 `main` 的 `7211c4148adcb4d235787269491f59d33a719e9b` 为基础，纳入当前工作区的高级检索、分面筛选、结果卡片、专家资料字段扩展、职称档位、向量缓存更新、子资源归属校验和相关测试。专家库各历史功能分支的提交已包含在该基础版本中；早期技术方案分支另行合并，作为历史设计记录。

归档时补充修复了两处问题：已发布专家修改职称或荣誉后立即更新派生档位和评分；分面接口返回空切片时，前端按空数组处理，避免已选单位标签渲染失败。

数据库备份、账号发放材料、临时渲染文件和本地维护工具二进制保留在本机，不纳入本次源码提交。
