## 推荐依据与排序修正

- 语义命中保留原始条目类型与关联记录 ID。成果依据按专家归属和成果 ID 回查，最佳纯语义来源优先进入最多四条依据，避免截断标题相同或证据被挤掉。
- 仅由同义词命中时会展示实际同义词，不再声称资料里出现了原查询词。
- 抽查发现，先前绝对优先新学科会将宽泛相邻话题选进推荐名单；现每轮先取满足单位/去重约束的最高主题相关性，只在差值不超过 0.05 的候选间比较多样性和原排序得分。该差值是开发阶段启发式，未经过标注集科学标定，未改变语义命中阈值 0.6。

- 候选可展示来源标题和记录 ID，但成果 ID 尚不能点击直达任意记录；旧详情页仍有前 100 条成果的展示限制。
